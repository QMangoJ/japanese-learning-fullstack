# IT 听力数据 · IT Listening data

学习区「IT 听力」(`/study/#/it-listening`) 读这里的文件。每篇文章一个 JSON，`index.json` 是目录。

```
public/data/it-listening/
  index.json              { "version": 1, "articles": [ {目录条目} ] }
  <id>.json               一篇文章（下面的结构）
```

## 目录条目（index.json）

```jsonc
{
  "id": "unit15-operation-demo",      // kebab-case，和文件名一致，网址是 /study/#/it-listening/<id>
  "title_zh": "「场景会话」Unit 15：操作演示",
  "title_ja": "「場面で覚える」Unit 15：オペレーションデモ",
  "series_zh": "场景会话",             // 系列分组（列表页按系列排序/标注）
  "series_ja": "場面で覚える",
  "unit": 15,
  "track": "TRACK 37",                // 可选：教材音轨编号
  "source": "まいにち日本語勉強（YouTube）",  // 来源频道名
  "channelUrl": "https://www.youtube.com/@mainichi.nihongo.benkyo",
  "youtube": "https://www.youtube.com/watch?v=…",   // 必填：原视频链接
  "videoId": "…",                      // 必填：YouTube 视频 ID（详情页嵌入播放器用）
  "durationSec": 260,                  // 可选
  "sentenceCount": 30
}
```

## `<id>.json`

目录条目的全部字段，外加：

```jsonc
{
  "note_zh": "…",                      // 可选：转录来源/处理说明，显示在详情页原文区上方
  "sentences": [
    {
      "speaker": "リー",               // 说话人（原文标注，如 リー / ユーザー）
      "jp": "では、次に売上データを追加してみましょうか。",   // 日文原句（逐句）
      "ruby": [                        // 注音分段（2026-11-08 Daniel 定）：各片段 t 依次拼接 == jp
        { "t": "では、" },
        { "t": "次", "r": "つぎ" },      // 带 r 的片段是汉字串，r 是它在句中的读音
        { "t": "に" },
        { "t": "売上", "r": "うりあげ" },
        { "t": "データを" },
        { "t": "追加", "r": "ついか" },
        { "t": "してみましょうか。" }   // 纯假名/标点片段不带 r
      ],
      "zh": "那么，接下来试着添加一下销售数据吧。",          // 中文翻译，必填
      "grammarPoints": [               // 语法层标准（2026-11-08 精炼版，见下节）：有价值才成条，不凑数
        { "level": "N2",                 // JLPT 级别
          "name": "「〜てもらいます」安排分工（非请求）",   // 语法点名（可带类别前缀，如「謙譲語：〜」）
          "explanationZh": "…" }         // 中文解析（精炼）：是什么 + 在本句的作用，1~2 句约 30~60 字
      ],
      "structure": "…",                // 可选：整句结构拆解（news 的 keySentences.structureZh），成分＋中文 gloss 以「＋」连接；只给结构复杂的长句
      "grammar": "…",                  // 旧式单段语法注（升级前的文章在用，新文章不再写）
      "vocab": [                       // 可选：该句值得记的生词，不要注水
        { "w": "売上データ", "r": "うりあげデータ", "pos": "名词", "zh": "销售数据",
          "origin": "英语 data" }       // 可选：外来语来源，见「生词来源」节
      ]
    }
  ]
}
```

## 语法层标准（精炼版，2026-11-08 Daniel 二次反馈定）

结构沿用阅读项目 news-learning 的体例（逐句挂载 `grammarPoints` 逐条列出、长句另给 `structure`），
但讲解**精炼**——Daniel 明确反馈：像「はい」这种不需要长篇语用讲解。本节口径覆盖 2026-11-08 早先的「写满 2~4 句」深度版。

- `explanationZh` 只写两件事：**是什么**（接续/构成，一句带过）+ **在本句里的作用**。一般 1~2 句、约 30~60 字；只有真正易错或有敬语陷阱的点才可到 ~100 字，并带一句「注意…」。
- 不写铺陈、重复定义、泛泛的学习建议；同一个点在多句出现时，后文从简，不要每句重讲一遍原理。
- 敬语（尊敬/自谦/丁重）、词汇搭配、语用功能（留半句、确认节奏等）有实际内容时才单独成条；一条只讲一个点。
- **纯应答/语气句**（「はい。」「そうです。」「すみません。」等）：**不加注，或最多一句十余至三十字的短注**，按句子存在感二选一——不许出现成段语用长文。
- 结构复杂的长句另给 `structure`（句干拆解，成分＋中文 gloss 以「＋」连接），它本身就是精炼体，保留。
- `name`、`level` 口径不变（语法点名可带类别前缀，如「謙譲語：〜」）。

## 注音（furigana）标准（2026-11-08 Daniel 定）

- 每句给 `ruby` 分段数组：片段对象 `{ "t": "…", "r": "…" }`，全部 `t` 依次拼接必须与 `jp` 逐字一致（生产时脚本断言）。
- 带 `r` 的片段只放汉字串，`r` 是该汉字串**在句中语境下**的读音（多音字逐个核，如 その後→ご、用→よう、実は→じつ）；纯假名、片假名、标点片段不带 `r`。
- 详情页渲染：带 `r` 的片段以 `<ruby>` 呈现，读音标在汉字上方；没有 `ruby` 字段的句子按纯文本 `jp` 显示（旧文章兼容）。
- **说话人名字同样注音**（2026-11-08 Daniel 追加）：句子可带 `speakerRuby`，与 `ruby` 同结构，片段 `t` 拼接必须与 `speaker` 一致。名字含汉字时给（如 `大沢`→`おおさわ`）；纯片假名名字（リー、ユーザー等）不给。渲染端说话人标签以 ruby 呈现名字读音。

## 解说文本的注音标记（2026-11-08 Daniel 追加）

语法注（`grammarPoints` 的 `name`、`explanationZh`）与 `structure` 里出现的日语，凡有汉字同样要带读音，
标准与原句注音一致（多音字按语境）。实现为**轻量标记**（数据仍是普通字符串，旧数据无标记照常渲染）：

- 写法：`{漢字|よみ}`，如 `「{持参|じさん}する」は「{持|も}って{行|い}く」の鄭重語`。
- 标记只包汉字串本身，送假名写在标记外（如 `{選|えら}びください`）。
- 渲染端（`parseRubyMarkup`）把标记解析成 `<ruby>` 片段；不成对的括号原样显示，不会吞字。
- 生产时断言：把标记剥掉（`{x|y}`→`x`）必须与未标记原文逐字一致。

## 生词来源（外来语，2026-11-08 Daniel 追加）

- 生词条目可带 `origin` 字段：`"<来源语言中文名> <原词>"`，如 `"英语 user"`、`"德语 Arbeit"`、`"葡萄牙语 pão"`、`"法语 enquête"`。来源不限英语，任何外语来源都标。
- 只给**片假名外来语**（含复合词里的外来语成分，如 商品マスター 的 マスター 部分）且**来源明确**的词加；和语、汉语词不加。
- **来源不确定、和制英语**（如 サラリーマン 这类日本自造词）**不硬凑、不加**。
- 页面展示：生词行末尾以「← 英语 user」形式呈现。
